The call table

Every call of profile 1, device by device: the number that goes in a7, the arguments, the result and the class that sets the base charge. How a program makes a call, and what an unknown call or a bad buffer returns, is in the article on the Terse32 machine; each device's article describes its calls in full.

Class sets the base charge: 4 for a deferred call (its result and charge follow from its arguments), 64 for an answered one (they depend on the device's state). System and Machines calls cost 4.
