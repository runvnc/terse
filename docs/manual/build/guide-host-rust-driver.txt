# Make a host in Rust, step 3: a driver shows hello

Text on a Terse32 screen comes from device 2, the terminal: 80 by 30 character cells. Rather than write it, use the device bus: each device is a separate program, a driver, that talks to your core over a Unix-domain socket. The Tersenet sources have a reference driver for every device. This step adds the module `bus`: start one driver, the terminal's, pass it the terminal's calls, and ask it for the grid to print.

The reference drivers are in the downloads' `bus` folder, for Linux, macOS and Windows. Or build them from the top folder of the sources:

```
cargo build --release -p terse-devices
```

## Messages

Every message is a length (4 bytes, of the rest), an address (the machine, 4 bytes, always 0 here; a slot; 3 zero bytes) and a body whose first byte is its type. Integers are little-endian. `send` writes one; `request` writes one and reads the reply, whose type must be the request's plus `REPLY`. Anything else, an `ERROR` from the driver included, ends the run with status 3 (`fail`):

```rust from examples/host/rust/src/bus.rs
const HELLO: u8 = 0x01;
const OPEN: u8 = 0x03;
const CALL: u8 = 0x10;
const BEGIN: u8 = 0x30;
const END: u8 = 0x31;
const STATE: u8 = 0x40;
const SHUTDOWN: u8 = 0x60;
const REPLY: u8 = 0x80;
const PROTOCOL: u8 = 1;
const ADDRESS_SIZE: usize = 8;
const NO_SLOT: u8 = 0;
```

```rust from examples/host/rust/src/bus.rs
    fn send(&mut self, slot: u8, body: &[u8]) {
        let length = (ADDRESS_SIZE + body.len()) as u32;
        let mut message = length.to_le_bytes().to_vec();
        message.extend([0, 0, 0, 0, slot, 0, 0, 0]);
        message.extend(body);
        check(self.stream.write_all(&message));
    }

    fn request(&mut self, slot: u8, body: &[u8]) -> Vec<u8> {
        self.send(slot, body);
        let mut length = [0; 4];
        check(self.stream.read_exact(&mut length));
        let mut reply = vec![0; word(&length, 0) as usize];
        check(self.stream.read_exact(&mut reply));
        let reply = reply.split_off(ADDRESS_SIZE);
        if reply.first() != Some(&(body[0] | REPLY)) {
            let text = String::from_utf8_lossy(&reply);
            fail(format!("the driver said {text:?}"));
        }
        reply
    }
```

## Starting the driver

```rust from examples/host/rust/src/bus.rs
    pub fn start(
        command: &str,
        cpu: &Cpu,
        file: &[u8],
        devices: &[Device],
    ) -> Bus {
        let name = format!("terse-bus-{}", std::process::id());
        let dir = env::temp_dir().join(name);
        check(fs::create_dir_all(&dir));
        let path = dir.join("bus.sock");
        let listener = check(UnixListener::bind(&path));
        let driver = check(
            Command::new(command)
                .env("TERSE_BUS_SOCKET", &path)
                .stdout(stderr())
                .spawn(),
        );
        let (stream, _) = check(listener.accept());
        let session = dir.to_string_lossy().into_owned();
        let (tables, grants) = (HashMap::new(), Vec::new());
        let mut bus =
            Bus { stream, driver, dir, tables, grants };

        let ask: Vec<u8> = devices
            .iter()
            .map(|d| d.slot)
            .filter(|slot| [TERMINAL, FULL_TEXT].contains(slot))
            .collect();
        let mut hello = vec![HELLO, PROTOCOL, 0, 0];
        hello.extend([0, 0, 0, 0, ask.len() as u8]);
        hello.extend(&ask);
        hello.extend((session.len() as u16).to_le_bytes());
        hello.extend(session.as_bytes());
        hello.extend([0, 0]);
        let reply = bus.request(NO_SLOT, &hello);
        let mut rest = &reply[NAME_AT..];
        let mut take = |n: usize| rest.split_off(..n).unwrap();
        let length = take(LENGTH_SIZE);
        let length = u16::from_le_bytes([length[0], length[1]]);
        take(length as usize + NATIVE_SIZE);
        let mut versions = HashMap::new();
        for _ in 0..take(1)[0] {
            let (slot, version) = (take(1)[0], take(1)[0]);
            let layers = take(1)[0] as usize;
            take(LAYER_SIZE * layers);
            for _ in 0..take(1)[0] {
                let entry = take(ENTRY_SIZE).to_vec();
                let function = entry[FUNCTION_AT];
                let key = (slot as u32, function as u32);
                bus.tables.insert(key, entry);
            }
            versions.insert(slot, version);
        }

        let mut has = Vec::new();
        for d in devices {
            let (slot, version) = (d.slot, d.version);
            let granted = versions.get(&slot) == Some(&version);
            if !granted && !d.optional {
                fail(format!("no driver for device {slot}"));
            }
            if d.optional {
                bus.grants.push(granted as u8);
            }
            if granted {
                has.extend([d.slot, d.version]);
            }
        }
        let mut open = vec![OPEN, 0, 0, 0];
        open.extend(blake3::hash(file).as_bytes());
        let (rom, ram) = (cpu.rom.len(), cpu.ram.len());
        words(&mut open, &[rom as u32, ram as u32]);
        open.extend([0, 0, (has.len() / DEVICE_SIZE) as u8]);
        open.extend(&has);
        open.push(0);
        open.extend(&cpu.rom);
        if bus.request(NO_SLOT, &open)[TOOK_AT] != TOOK {
            fail("the driver will not run the program");
        }
        bus
    }
```

In order:

- Listen on a socket in a new directory, start the driver with the socket's path in `TERSE_BUS_SOCKET`, and accept its connection.
- HELLO (`01h`) asks for the slots the program lists among 2 (the terminal) and 10 (full text, which goes with it), and names the directory; the four zero bytes are flags, the last two an empty bus file. The reply, from `NAME_AT`: the driver's name (a u16 length, then the bytes), its native size, then for each slot its number, version, layers (`LAYER_SIZE` bytes each) and call table: 64 bytes per function, which says where the call's buffer is and what the call costs. `tables` keeps each entry by slot and function.
- Grants: a device the program requires and the driver does not serve stops the run; an optional one is granted if the driver serves it, in the version the program lists. `hello` requires 2 and lists 10 as optional.
- OPEN (`03h`) gives the driver the machine: its image ID, the BLAKE3 hash of the program file; the ROM and RAM lengths; an empty memory file (two zero bytes); the slots it has; no program identity (0); the ROM. The reply says if the driver took it.

## Calls through the table

```rust from examples/host/rust/src/bus.rs
    pub fn call(
        &mut self,
        cpu: &mut Cpu,
        budget: i64,
        slot: u32,
        function: u32,
    ) -> (u32, i64) {
        let key = (slot, function);
        let Some(entry) = self.tables.get(&key).cloned() else {
            return (UNKNOWN_CALL, BASE_CHARGE);
        };
        let field = |at| word(&entry, at);
        let flags = entry[FLAGS_AT];
        let access = entry[ACCESS_AT];
        let mut charge = ANSWERED_CHARGE;
        if flags & DEFERRED != 0 {
            charge = BASE_CHARGE;
        }
        let args = cpu.x[A0..=A5].to_vec();
        let addr = args[entry[BUFFER_AT] as usize];
        let mut size = 0;
        if flags & BUFFERED != 0 {
            size = field(SCALE_AT) as u64;
            if entry[LENGTH_AT] != NONE {
                size *= args[entry[LENGTH_AT] as usize] as u64;
            }
            let least = field(LEAST_AT) as u64;
            if size < least || size > field(MOST_AT) as u64 {
                return (field(LENGTH_RESULT_AT), charge);
            }
            let ram_only =
                access & IN_ROM == 0 || access & WRITES != 0;
            let place = cpu.memory(addr, size as u32, ram_only);
            if place.is_none() && size > 0 {
                return (field(PLACE_RESULT_AT), charge);
            }
        }
        let checked = entry[CHECKED_AT];
        let most = field(CHECKED_MOST_AT);
        if checked != NONE && args[checked as usize] > most {
            return (field(PLACE_RESULT_AT), charge);
        }

        let mut call = vec![CALL, function as u8, 0, 0];
        words(&mut call, &args);
        call.extend((budget - BASE_CHARGE).to_le_bytes());
        let reads = if access & READS == 0 { 0 } else { size };
        words(&mut call, &[reads as u32]);
        if reads > 0 {
            let buffer = cpu.memory(addr, reads as u32, false);
            call.extend(&*buffer.unwrap());
        }
        let reply = self.request(slot as u8, &call);
        if reply[FLAGS_AT] & SETS_A1 != 0 {
            cpu.x[A1] = word(&reply, A1_AT);
        }
        let mut at = WRITES_AT;
        for _ in 0..word(&reply, WRITE_COUNT_AT) {
            let write = &reply[at..];
            let to = word(write, 0);
            let length = word(write, WRITE_LENGTH_AT);
            let offset = to.wrapping_sub(addr) as u64;
            let outside = offset + length as u64 > size;
            if access & WRITES == 0 || outside {
                fail("a write outside the buffer");
            }
            let data = &write[WRITE_DATA_AT..];
            let target = cpu.memory(to, length, true).unwrap();
            target.copy_from_slice(&data[..target.len()]);
            at += WRITE_DATA_AT + length as usize;
        }
        let extra = word(&reply, CHARGE_AT) as i64;
        (word(&reply, A0_AT), charge + extra)
    }
```

A function the table does not have is a call the machine does not have: `FFFF_FFFFh`, charge 4. Otherwise the charge starts at 4 for a deferred call (flag 2: its result and charge follow from its arguments) or 64 for one the driver must answer. Before anything is sent, the table's checks: the buffer's length within its range, the buffer wholly in RAM (or in ROM, for one the device only reads), and a checked argument no larger than its limit; a call that fails gets the table's failure result and goes no further. Then CALL (`10h`) carries `a0` to `a5`, the budget, and the bytes of a buffer the device reads, and RESULT (`90h`) gives `a0`, maybe `a1`, the charge on top, and bytes to write into the call's buffer.

The `…_AT` names are offsets in an entry and in RESULT; `DEFERRED`, `BUFFERED`, `READS`, `WRITES` and `IN_ROM` are the entry's flag and access bits, and `NONE` (`FFh`) no argument. All of them: DEVICES.md sections 1.4 and 5.

## Frames

BEGIN (`30h`) starts each frame: the frame counter, the time (0 here), no input events, an empty replay field. The reply, INPUTS, may charge the frame and bring events; the terminal does neither, and this host reads only the charge:

```rust from examples/host/rust/src/bus.rs
    pub fn begin(&mut self, frame: u32) -> i64 {
        let mut begin = vec![BEGIN, 0, 0, 0];
        words(&mut begin, &[frame, 0, 0, 0]);
        let reply = self.request(NO_SLOT, &begin);
        word(&reply, INPUTS_CHARGE_AT) as i64
    }
```

END (`31h`) ends the frame, with no reply. STATE (`40h`, `state`) asks for a slot's part of the machine's state; the terminal's starts with its 2,400 cells, 4 bytes each: a character (16 bits), a foreground and a background colour. SHUTDOWN (`60h`, `close`) stops the driver:

```rust from examples/host/rust/src/bus.rs
    pub fn end(&mut self, frame: u32, stopped: bool) {
        let mut end = vec![END, stopped as u8, 0, 0];
        words(&mut end, &[frame]);
        self.send(NO_SLOT, &end);
    }

    pub fn state(&mut self, slot: u8) -> Vec<u8> {
        self.request(slot, &[STATE]).split_off(SECTION_AT)
    }

    pub fn close(mut self) {
        self.send(NO_SLOT, &[SHUTDOWN]);
        check(self.driver.wait());
        check(fs::remove_dir_all(&self.dir));
    }
```

## The program

```rust from examples/host/rust/src/bin/step3.rs
use host::bus::{Bus, TERMINAL};
use host::frames::{Machine, Status};
use host::image::load;
use std::error::Error;
use std::process::exit;

fn main() -> Result<(), Box<dyn Error>> {
    let args: Vec<String> = std::env::args().collect();
    let file = std::fs::read(&args[1])?;
    let frames: u32 = args[2].parse()?;
    let (cpu, devices) = load(&file)?;
    let mut bus = Bus::start(&args[3], &cpu, &file, &devices);
    let mut m = Machine::new(cpu);
    while m.running() && m.frame < frames {
        m.budget -= bus.begin(m.frame);
        m.run_frame(|cpu, budget, slot, function| {
            bus.call(cpu, budget, slot, function)
        });
        bus.end(m.frame, !m.running());
    }
    print!("{}", screen(&bus.state(TERMINAL)));
    bus.close();
    match m.status {
        Status::Faulted(fault) => {
            eprintln!("{fault}");
            exit(1)
        }
        Status::Exited(code) => exit(code as i32),
        Status::Running => Ok(()),
    }
}

const COLUMNS: usize = 80;
const ROWS: usize = 30;
const CELL_SIZE: usize = 4;
const CONTINUATION: u16 = 0xffff;

fn screen(grid: &[u8]) -> String {
    let code = |cell: usize| {
        let at = CELL_SIZE * cell;
        u16::from_le_bytes([grid[at], grid[at + 1]])
    };
    let mut text = String::new();
    for row in 0..ROWS {
        let mut line = String::new();
        for col in 0..COLUMNS {
            let cell = row * COLUMNS + col;
            let right_half =
                col > 0 && code(cell - 1) != CONTINUATION;
            match code(cell) {
                CONTINUATION if right_half => {}
                CONTINUATION => line.push(' '),
                c => line += &String::from_utf16_lossy(&[c]),
            }
        }
        text += line.trim_end_matches(' ');
        text += "\n";
    }
    text
}
```

`screen` prints the grid as `terse run --dump` does: a row's 80 cells, stripped of spaces at the end. `FFFFh` in a cell is the right half of a wide character, skipped after the character, else a space.

## Run it

From `examples/host/rust`, after `cargo build --release`:

```
target/release/step3 ../../../programs/hello/hello.terse 30 \
    ../../../target/release/terse-dev-terminal
```

prints `hello`'s screen after 30 frames, 30 lines, which begins

```
 Tersenet · hello

  héllo, wörld — привет, мир
  Ελληνικά · кириллица · ┌─┬─┐ · ♥ ★ ✓
```

and is the reference's exactly: from the top folder, `terse run programs/hello/hello.terse --frames 30 --dump` prints the same 30 lines.

The driver can be any program that speaks the bus. [Make a device in Rust](terse:66e4cb92b7c491b3213dfd8941bcb1503d09c832c9e8d822bcc287dbaa230309) writes a terminal of 347 lines that is enough for `hello`; give its path instead of the reference's. So can a driver in another language: the Go one of "Make a device in Go" works here too.
