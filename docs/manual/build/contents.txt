# Contents

The manual has three parts. The user guide gets you from installing Tersenet to reading, publishing and following others, with no programming. The implementation guide builds the parts of Tersenet yourself, from working source code: a reader, programs, a host, a device and a shell. Both are short steps, each one you can finish in a sitting. The reference is everything, complete and exact.

## User guide

- [Install Tersenet](terse:2be70a69df3d87cbf14aad511d3b4205188a06082c61b9cbb17c4767df4dcac5): one command on Linux and macOS, a zip on Windows, or from the source.
- [Run Tersenet](terse:87b5fd929801cf708fe6f8226926b878b1662aa8041848312b0271b50cfcbead): the window, the launcher, the reader and this manual.
- [Create your profile](terse:7895a6e0bf9e691188e84a62091e5701823a23f5784bce9477a397f8af85fef2): your key, your name and your address; no account needed.
- [Write and publish an article](terse:42c988cbd9a281f2de36f98be778c617593d7d46b815529f952dfd8dde9188d1): a plain text file, how it compares with Markdown, and your feed.
- [Read articles and follow links](terse:dd2b8b6d26b6dabe2d3bcad1b1ad27d98b9aac64c64094f69626ab381a75bcae): the timeline, links and search.
- [Subscribe to someone's feed](terse:95e525b49dce9d34c6bba6227489de8b911b5b1b72787b97d9c86f0f029b2352): a shared relay, by address or by name, nicknames.
- [Find and play a game](terse:43d792d6e615d8ba96eb25353bf047c44ffdc6a5c6b9a344dc0c1f4afc625f65): the built-in game, programs from feeds and links, saving your place.

## Implementation guide

- [Make a reader, step 1: show an article](terse:dbc6cb95d6b5e296b77627c123877893b5a04194bec439cf465987085dfefcbf): the article format's first rules, and a test to check yourself.
- [Make a reader, step 2: fetch an article](terse:fe1219169e748add706a2be87914caab2b3d21da9af1349be54265fb6bc09cb9): get an article from a relay and check that it is genuine.
- [Make a reader, step 3: links and feeds](terse:9e309ed175942813e44ac035c4554e91fc6b315b7726961e63005362dc51b8b3): follow links, subscribe to a feed, check its signatures.
- [Write a program in C](terse:71758fe9cbfff354025db6496540eb46e5fea492bfcdb73cdb7ccba93f043f99): hello on the text grid, built, run in a window and tested without one; Go has no compiler for Terse32, so the program pages are in C and Rust.
- [Write a program in Rust](terse:bfa5fc4aba30f10adbbaf0ab609786e5e5855cff84a429f27c8f02199780ff88): the same program with the Rust runtime.
- [Draw a line and read a key](terse:bfe1b08acf80be2bc45e19a8caca2cba3dbb0e6c5ab0d05a0b70708a0c571d85): a line on the 2D vector display that the arrow keys move, in C.
- [Draw a line and read a key in Rust](terse:a7e445931915d6fbba76684f5111f9ae2859ba89ee6ade8210e8395fd1c8d760): the same with `VecList`.
- [Make a small game](terse:25579f0d099a07b1582236d877154448853adf2ccc67bc733ac21c9b59d675d7): steer a dot to a ring, keep score; the way to sparks and Lumen Reef, in C.
- [Make a small game in Rust](terse:bbb12d81256b383b29aa6700e83da29a6450291a3121068b4a600ebe85d44b44): the same game in Rust.
- [Make a host, step 1: run a program to its end](terse:0106a8ebd4989f4a58029825185e6e203cc6e34de3aca8aebb4e1c4f322d5a8b): the program file, memory and the processor, until `exit`.
- [Make a host, step 2: frames and the budget](terse:7ea7a58ea0fc29dc9e961217f2eb89fb210340dd7b353f530b929c147692370c): 125,000 units a frame, `wait_frame` and the carry rule.
- [Make a host, step 3: a driver shows hello](terse:c1090f2dcc0db6881e93710dd6aa5c797d90209926cb7993f61b12416fd75799): the reference terminal over the device bus.
- [Make a host, step 4: prove it exact](terse:93f915d95f13b48ff01473ddc657ecaf593233d0f492d50c6e6e1ed38a027cda): the state hash, snapshots and the conformance program.
- [Make a device](terse:f5d9c510c9d4873ce1ba321e2599cabb425f471eba21f399df16470e94d603eb): a device as a separate program on the device bus.
- [Swap in your own part](terse:96945e0522104f15356fc48fbb7bd43c39f86798461795bebd2aac03727a5dbe): your reader, core or device with the reference for everything else.
- [Make a shell](terse:2d3dca3c003d38b55b52f52a7426a2f5dc9a4e6e542a9e1cdff158cfef9ad1ad): a program that starts another machine and shows it (device 8), in C.
- [Make a shell in Rust](terse:d0b845208cc8c0d07740878eda9a8a1f75477ab971dd2dd7abe4bfc0ab0daece): the same shell with the runtime's calls of device 8.
- [Invent a device](terse:af57a98aa4b2acc69882dc0371aa062c0f595dc87388d62e98efb8a4a8f16fba): an experimental device, its driver in C and a program in C that uses it.
- [Invent a device: the program in Rust](terse:e6394bccb8d3e12b4e661acf3ff263cb01e1f2b21a77b8ce366588cb7b5c8035): the same program in Rust, with raw calls.
