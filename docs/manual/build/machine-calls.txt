# The call table

Every call of profile 1, device by device: the number that goes in `a7`, the arguments, the result and the class that sets the base charge. How a program makes a call, and what an unknown call or a bad buffer returns, is in the article on the Terse32 machine; each device's article describes its calls in full.

Class sets the base charge: 4 for a deferred call (its result and charge
follow from its arguments), 64 for an answered one (they depend on the
device's state). System and Machines calls cost 4.

[The system device](terse:257635553a7ec3a579827e3abd00005ff4778e8f673dfd1d4d4ad3aa26f4a4de), slot 1, always present:

| `a7` | Call | Arguments | Result |
|---|---|---|---|
| `100h` | `wait_frame` | none | the frame counter in the frame it returns in |
| `101h` | `next_event` | `a0` = buffer (4 bytes, written) | 1 and the event, or 0 if the queue is empty |
| `102h` | `frame_count` | none | the frame counter |
| `103h` | `unix_time` | none | the Unix time latched at the start of the frame |
| `104h` | `random` | `a0` = buffer (written), `a1` = length, at most 256 | the length |
| `105h` | `controller` | `a0` = controller number, `a1` = buffer (8 bytes, written) | byte 0 of the state |
| `106h` | `exit` | `a0` = exit code (low 8 bits) | does not return |
| `107h` | `open` | `a0` = address of an open request (read) | 1 passed to the shell, 0 not |
| `108h` | `argument` | `a0` = buffer (32 bytes, written) | 1, or 0 if the machine has none |
| `109h` | `device` | `a0` = device slot | its version, or `FFFF_FFFFh` if absent |
| `10Ah` | `copy` | `a0` = text (read), `a1` = length, at most 65,536 | 0 (the host takes it only for the user's copy key, Enter or press) |
