# Make a shell

When `terse-host` opens, the first thing you see, the launcher with its tiles, is not part of the host. It is a Terse32 program like any other, the shell, with one device the others lack: Machines, device 8, which starts other machines and says where their screens go. You can write your own, in C here or in Rust on [the next page](terse:86e0271b98c677cedd0592921ff875a5c6cc96b013753db412eca9617305d748).

## The smallest shell

`myshell.c` starts the built-in program `hello` and gives it the whole screen and the keyboard:

```c examples/program/c/myshell.c
#include "terse.h"

static const uint8_t built_in[32];

int main(void)
{
    uint32_t hello = mach_start_named(built_in, "hello", 5);
    mach_place(hello, 0, 0, 640, 480);
    mach_focus(hello);
    for (;;)
        terse_wait_frame();
}
```

- `mach_start_named` starts a program by its publisher's key and its name, with the name's length (5); 32 zero bytes, `built_in`, mean a program built into the host. It returns a handle, 1 to 8 (0 if all eight are in use).
- `mach_place` sets the rectangle of the shell's screen where that machine's screen is shown: here all of it, 640 by 480 units.
- `mach_focus` sends the keyboard to that machine.

Each machine is a whole separate Terse32 machine, with its own memory, devices and budget. The shell only decides what runs and where it is seen.

## Build it and run it

A shell lists device 8; this one needs nothing else:

```
terse build myshell.c --device 8:0
terse run --shell myshell.terse --frames 30 --dump
```

The run prints the shell's own screen, then each machine's:

```
terse: image has no terminal device
-- machine 1 running 0 0 640 480 hello --
 Tersenet · hello
  héllo, wörld — привет, мир
```

and the rest of hello's screen. The first line says only that the shell itself has no text grid to print. In a window:

```
terse-host --shell myshell.terse
```

## Where to take it

From here a shell is a matter of taste: a list of programs to choose from (`mach_builtin` lists the built-in ones), several machines tiled side by side, a key that brings the shell back (the host sends it a home event), saving and restoring machines. The reference shell, `programs/shell/shell.c`, does all of these in about 2,000 lines of C.
