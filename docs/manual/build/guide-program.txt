# Write a program

Besides articles, Tersenet can carry small programs. Each runs on its own Terse32 machine, a tiny virtual computer: at most 1 MiB of memory, a fixed amount of work per frame at 60 frames a second, and a few devices to talk to, such as an 80 by 30 grid of text and a display for lines and shapes. A program cannot see your files, and before one publishes anything in your name or changes the feeds you follow, the host asks you. Programs are optional: nothing in the reader depends on them.

## Three commands

```
terse new hello.c
terse build hello.c
terse-host hello.terse
```

`terse new` writes a small C program to start from. `terse build` compiles it into `hello.terse`, the program file, with the text grid and the line display as its devices. `terse-host` runs it in a window; closing the window ends it.

The same works in Rust: `terse new hello.rs`, then `terse build hello.rs`.

## What a program looks like

A whole program can be this short:

```
#include "terse.h"

int main(void)
{
    term_puts("Hello, Tersenet!");
    for (;;)
        terse_wait_frame();
}
```

`term_puts` writes text on the grid. `terse_wait_frame` says "done for this frame": the program sleeps until the next one. There are no threads and no interrupts; a program does a frame's work, then waits. If it does too much, the machine simply pauses it and carries on in the next frame.

## Run it without a window

```
terse run hello.terse --frames 30 --dump
```

runs it for 30 frames with no window and prints the text grid. That is how programs are tested: the machine is deterministic, so the same program with the same input gives the same result on every computer.

## Share it

```
terse feed publish --program hello.terse
```

publishes it in your feed, under its name (make your key first with `terse key new`, once). People who follow your feed see it in the launcher of `terse-host` and can start it with Enter.
