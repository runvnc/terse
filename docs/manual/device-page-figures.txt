# Figures on the page

A figure is a drawing between the paragraphs of a page document: a box of a given size, drawn from paths of straight lines and Bezier curves, filled and stroked. It is the Figure command (08h) of the page device, version 0 of device slot 7. Like the rest of the page it is drawn by the host, outside the machine's frames; three caps bound the work of each figure.

```path 240 80
fill #20304a stroke none M0 0 H240 V80 H0 Z
fill #e06c75 stroke fg 2 M20 70 L60 10 100 70 Z
fill none stroke #61afef 3 M120 60 C150 0 190 0 220 60
```

The box above is one filled path; the triangle is a path filled red and stroked in the text colour 2 units wide; the blue curve is a cubic segment, stroked only.

## The Figure command

| Offset | Size | Field |
|---|---|---|
| 0 | 1 | Opcode `08h` |
| 1 | 2 | Width in screen units, clamped to 1..1024 |
| 3 | 2 | Height, clamped to 1..1024 |
| 5 | 1 | Align: 0 start (left), 1 centre, 2 end (right); anything else 0 |
| 6 | 2 | n, the length of the path commands |
| 8 | n | The path commands |

If the n bytes run past the end of the document, the command is cut off and the document ends before it.

- Placement. A figure ends the current paragraph and is a block of its own, as high as its height. Above it is the space of the latest Paragraph command (or of the implicit first paragraph). If the current paragraph has no text yet, the figure takes its place and that paragraph's space is the space above the figure. Text after a figure starts a new paragraph with the properties of the latest Paragraph command.
- Horizontal place. The figure is placed in the rectangle's whole width, without indent: start is the left edge, centre puts half the leftover width before it (the reference layout rounds down), end all of it. Align is left or right, not relative to text direction.
- A figure wider than the rectangle starts at the left edge and is cut off at the right edge; it is not scaled. All drawing is clipped to the figure's box.
- The text colour and the anchor in effect at the Figure command belong to the figure: the colour is its initial stroke colour, and a press anywhere in its box as shown (cut off at the rectangle's edge) reports the anchor with event 09h. `locate` finds a figure like a line of text.

## Path commands

Each command is an opcode byte and its operands. Coordinates are signed 16-bit numbers in sixteenths of a screen unit from the figure's top left corner (x right, y down); colours are r, g, b, a, one byte each, a the opacity.

| Op | Command | Operands | Effect |
|---|---|---|---|
| `01h` | Fill | r, g, b, a | Ends the path; later paths are filled in this colour, not filled if a is 0 |
| `02h` | Stroke | r, g, b, a, width (2 bytes, unsigned, sixteenths) | Ends the path; later paths are stroked so, not stroked if a or width is 0 |
| `03h` | Move | x, y | Starts a subpath at (x, y) |
| `04h` | Line | x, y | Straight segment to (x, y) |
| `05h` | Quadratic | x1, y1, x, y | Quadratic Bezier to (x, y), control point (x1, y1) |
| `06h` | Cubic | x1, y1, x2, y2, x, y | Cubic Bezier to (x, y), control points (x1, y1), (x2, y2) |
| `07h` | Close | none | Straight segment back to the subpath's start, ending the subpath; nothing if none is open |
| `08h` | Layer | id (1 byte) | Ends the path; later paths are in layer id (below) |

Operand sizes: Fill 4 bytes, Stroke 6, Move and Line 4, Quadratic 8, Cubic 12, Close 0, Layer 1. The commands end at the end of the n bytes, at an unknown opcode or at a command whose operands are cut off; the ones before are used.

At the start: no fill; stroke in the document's text colour at the Figure command, opaque, 16 sixteenths (one unit) wide; current point (0, 0); no subpath open.

## Segments, subpaths and paths

- Each segment starts at the current point and ends at its end point, which becomes the current point.
- A segment with no subpath open (at the start, after a Close, a Fill or a Stroke) starts a subpath at the current point. After a Close the current point is the start of the subpath it closed.
- A path is the subpaths between two Fill or Stroke commands, or the start or end of the commands. Fill and Stroke change how later paths are drawn, never the path they end.
- Each path is filled with the non-zero winding rule, then stroked centred on its outline, with round joins and round ends. Later paths are drawn over earlier ones, blended by opacity.
- A path with no segment, or with neither fill nor stroke, draws nothing.

## Caps

Paths are drawn in order and counted against three caps per figure. The first path that would take a total above its cap is not drawn, and neither is any path after it. A path that draws nothing (no segment, or neither fill nor stroke) counts against none of them. The caps count the path commands alone: a figure drawn as outlines (below) counts its fills all the same.

| Cap | Limit |
|---|---|
| Paths | 256 |
| Area | 8 x width x height of the figure, and at most 4 x 640 x 480 = 1,228,800 square units |
| Length | 65,536 |

- Area. A path's points (each Move's point and each segment's start, control and end points) give a box, clipped to the figure's box. The path counts that box once if it is filled, and the box grown on every side by half the stroke width in sixteenths, rounded up, and clipped, once more if it is stroked. A box's area is its width times its height in sixteenths, divided by 256 and rounded up.
- Length. L is the sum, over the path's Line, Quadratic and Cubic commands, of |dx| + |dy| for each step from the segment's start through its control points to its end, in sixteenths; s is the number of those commands. A Close counts in neither. A filled path counts 2 x L + 4 x 16 x s, a stroked one 2 x L + 4 x w x s more with w its stroke width in sixteenths; the path's sum is divided by 16 and rounded up once.

Worked example: a figure 100 x 50 units, so the area cap is 8 x 100 x 50 = 40,000. One path, filled and stroked 2 units (32 sixteenths) wide: Move (160, 160), then Lines to (1440, 160), (1440, 640), (160, 640) and (160, 160), the rectangle from (10, 10) to (90, 40) in units.

- Fill box: 1,280 x 480 sixteenths, 614,400 / 256 = 2,400.
- Stroke box, grown by 16: 1,312 x 512, 671,744 / 256 = 2,624.
- Area 5,024 of 40,000.
- L = 1,280 + 480 + 1,280 + 480 = 3,520, s = 4.
- Fill count 2 x 3,520 + 4 x 16 x 4 = 7,296; stroke count 7,040 + 4 x 32 x 4 = 7,552; together 14,848 / 16 = 928 of 65,536.

So seven such paths fit this figure's area cap (35,168); an eighth would take the total to 40,192 and would not be drawn, nor anything after it. The length cap alone would allow 70.

## Layers

A program can show, hide, move, scale and mirror parts of a figure without submitting the document again: a painted scene with an actor in it, each frame of a walk a layer of its own, and the scenery in front of the actor in a later layer, hiding it by the order of the paths alone.

- Groups. A Layer command (`08h`, id 0..63) ends the path; the paths after it, up to the next Layer command or the end, are a group of that layer. An id above 63 ends the path commands. The paths before the first Layer command are the figure's base, which belongs to no layer. Several groups may share a layer. Fill, stroke and current point carry on.
- State. Each of the 64 layers is shown or hidden, has an offset (x, y) in sixteenths, a scale s of 1..256 and is mirrored or not; only `layer` sets it, and only reset clears it (shown, at (0, 0), 256, not mirrored: drawn where its paths are).
- Drawing. Groups are drawn in their order, each over the ones before: the base as it is, a hidden layer's group not at all, a shown layer's group as its picture (what its paths draw, clipped to the figure's box) with each point (x, y) drawn at (x0 + s x / 256, y0 + s y / 256), or (x0 - s x / 256, ...) when mirrored, then clipped to the figure's box. A scale below 256 only makes a picture smaller. How smoothly is the host's.
- Layers change neither the layout nor the figure's box: height, `locate` and presses are as without them.
- In outlines (below) the same groups are drawn in the same order, shown and placed the same; nothing being filled, a layer in front hides nothing.

| Limit | Value |
|---|---|
| Layers | 64 (ids 0..63) |
| Layer commands in a document | 64, counted over all its figures; later ones end their figure's path commands |
| Layered area | 614,400 square units (2 x 640 x 480) for a document |
| Scale | 1..256 256ths, never larger than drawn |

A figure with a Layer command is layered. Each of its groups, base included, has a box: the smallest box holding the boxes its drawn paths count for the area cap. The boxes' areas (width x height in sixteenths / 256, rounded up) of all groups of all layered figures add up to at most the layered area; the first path that would pass it is not drawn, nor any path after it in its figure. The three caps above count every path of every group, shown or hidden.

What a host does: it draws each group's picture once, when it lays the document out, outside the frames; in a frame where a layer changed it draws the shown pictures again, placed, which is at most the layered area of drawing. A `layer` call costs 4 units whatever it changes, and the host draws the page once a frame however many calls came.

## Outlines

When the vector display (device 3) is in the phosphor style or in fill mode 1, figures are drawn as outlines: nothing is filled, and a path that is filled but not stroked is stroked one unit wide in its fill colour. In the phosphor style they are light on the black screen like the rest of the page. An image without the vector display has the clean style and fill mode 0, so its figures are filled.

## Building a figure in C

While building a document (see The page (device 7)), the library's path builder writes these commands and `doc_figure` wraps them in a Figure command, whose head is `DOC_FIGURE_HEAD` (8) bytes. This is the red triangle above, in a box of 120 x 80 units:

```
static uint8_t path[64];
path_begin(path, sizeof path);
path_fill(224, 108, 117, 255);
path_stroke(229, 229, 229, 255, 32);
path_move(320, 1120);
path_line(960, 160);
path_line(1600, 1120);
path_close();
doc_figure(120, 80, DOC_CENTRE, path, path_length(path));
```

`path_layer(id)` writes a Layer command; `page_layer(id, flags, x, y, scale)` is the call, with `PAGE_LAYER_SHOWN`, `PAGE_LAYER_MIRRORED` and `PAGE_SCALE_FULL` (256). A pose painted with its feet at (30, 168) units, shown with its feet at (fx, fy) sixteenths at scale s:

```
page_layer(3, PAGE_LAYER_SHOWN, fx - (30 * 16 * s >> 8), fy - (168 * 16 * s >> 8), s);
```

`programs/painted-test` builds a whole scene this way.

## Figures in articles

The article format writes a figure as text: a fence whose opening line is three backquotes, `path`, the width W and the height H (1..1024 units each, 1 to 4 digits with no sign; a column of the recommended width, about 68 characters of body text, is 512 units), holding a path string up to a closing line of three backquotes. The path string is SVG path data:

| Command | Numbers | Meaning |
|---|---|---|
| `M` | 2 | Move; more pairs after it are lines |
| `L` | 2 | Line |
| `H`, `V` | 1 | Horizontal or vertical line |
| `C` | 6 | Cubic curve |
| `S` | 4 | Smooth cubic: first control point reflected |
| `Q` | 4 | Quadratic curve |
| `T` | 2 | Smooth quadratic: control point reflected |
| `Z` | 0 | Close the subpath |

- Lowercase commands are relative to the current point. More numbers after a command's last one repeat it. The first command is `M` or `m`. There are no arcs.
- `fill <colour>` and `stroke <colour> [<width>]` may stand wherever a command may and set how the following subpaths are drawn; until the first one, no fill and stroke `fg` 1 unit wide. A word ends the path so far.
- `layer <n>` (1 or 2 digits, 0..63) puts the following paths in layer n and changes nothing else. In an article every layer is drawn, in order, where its paths are: the word only ends a path. It is there so that one figure text serves an article and a program (whose layers the page can move); readers older than the word find it malformed. Colours: `#rgb`, `#rrggbb`, `#rrggbbaa` (aa the opacity), `none`, `fg` (the text colour). A width is 0..2047 units; 0 draws no outline.
- Numbers have an optional sign and decimal point, at most 32 characters, no exponent; separators are blanks, line breaks and commas, or nothing where unambiguous (`M10-5`, `L5 5L6 6`); a word starts the path string or follows a separator (`L5 5fill` is malformed). Every number is rounded to the nearest sixteenth (halves away from zero), and every point reached, control points included, must lie within plus or minus 2047 units as written, before rounding (a relative point: the current point plus the numbers as written); a width likewise lies within 0..2047 as written.
- Anything else makes the figure malformed, and it is shown as the text of its fence.

The reader turns each figure into a Figure command this way:

- Centred, W x H units, one screen unit each (its column, 512 screen units, has the recommended width, so figures are at their natural size); if W is over 512, scaled down to 512 x round(H x 512 / W), at least 1, with every coordinate and width scaled by 512 / W after rounding to sixteenths (halves away from zero); a width that comes to 0 becomes 1, and the initial 1-unit stroke is scaled too.
- Coordinates become absolute sixteenths: `M` is Move, `L`, `H` and `V` Line, `Q` and `T` Quadratic, `C` and `S` Cubic, `Z` Close, with the reflected control points of `S` and `T` worked out. A Move is put before the first segment after a `Z` or a word unless that is an `M`.
- `layer` becomes a Stroke command repeating the stroke in force (it ends the path), not a Layer command, so the page's layer limits never cut an article.
- `fill` becomes Fill and `stroke` Stroke; colours become r, g, b, a, with `fg` the reader's body text colour (218, 218, 218) opaque and `none` alpha 0. A `stroke` without a width gets 1 unit. The document's text colour at the figure is the body colour, so the initial stroke is `fg`.
- A figure that is malformed, has no closing fence line, or whose commands do not fit in the document (or in 65,535 bytes) is shown as the fence's text.

The source of the figure at the top of this article:

    ```path 240 80
    fill #20304a stroke none M0 0 H240 V80 H0 Z
    fill #e06c75 stroke fg 2 M20 70 L60 10 100 70 Z
    fill none stroke #61afef 3 M120 60 C150 0 190 0 220 60
    ```
